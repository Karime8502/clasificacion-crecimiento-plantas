# Modelos entrenados

Esta carpeta contiene los pesos finales de los modelos entrenados
(archivos `.keras`), generados por `codigo/entrenar.py`:

- `modelo_cnn.keras` — CNN entrenada desde cero.
- `modelo_mobilenet.keras` — MobileNetV2 con Transfer Learning.

Si los archivos son muy grandes para GitHub, considerar usar
[Git LFS](https://git-lfs.com/) o dejar el enlace de descarga (Drive)
aquí mismo.
